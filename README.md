# Network Packet Analyzer

**Tech Stack:** Python, Scapy, Raw Sockets, Rich

- Built a real-time network packet analyzer capable of capturing and monitoring TCP, UDP, and DNS traffic from live network interfaces.
- Implemented raw socket-based packet capture and protocol-aware parsing of IP, TCP, UDP, and DNS headers to extract network metadata and traffic insights.
- Developed packet filtering, traffic analytics, and an interactive CLI dashboard for real-time protocol statistics and network activity monitoring.
